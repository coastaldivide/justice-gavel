# docs/fix-notes — change history, not documentation

These files are the working notes and change logs written while the platform
was being repaired and hardened (the "10/10" step series and earlier fix
passes): what was broken, what was changed, and the verification numbers at
the time each note was written.

**They are history.** Nothing in here is kept up to date, and statements in
these notes describe the codebase *as of the note's date*, not today. For
current documentation see:

- [README.md](../../README.md) — what the app is, architecture, quick start
- [DEPLOY_ENV_SETUP.md](../../DEPLOY_ENV_SETUP.md) — environment variables + deploy (Render)
- [LEAD_DEVELOPER_HANDOFF.md](../../LEAD_DEVELOPER_HANDOFF.md) — start here
- [API_REFERENCE.md](../../API_REFERENCE.md) / [openapi.json](../../openapi.json) — the API
- [RUNBOOK.md](../../RUNBOOK.md) — operations and incidents

Superseded *documentation* (as opposed to change logs) lives in
[docs/archive/](../archive/).
